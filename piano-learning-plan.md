## Key decision: iPad or Windows PC?

Short version — **use the Windows 11 PC, not the iPad**, for the actual learning tool. Here's why:

| | iPad | Windows PC |
|---|---|---|
| Free MIDI software | Almost none (GarageBand works but isn't a learning tool) | Tons — PianoBooster, Synthesia trial, MuseScore, web tools |
| Web MIDI API (browser-based learning sites) | Not supported in iOS Safari/Chrome | Fully supported in Chrome/Edge |
| Synthesia-style "falling notes" free | No truly free option | PianoBooster is free + open source |
| Sheet music + playback sync free | No | MuseScore.com (free account) |

Keep the iPad for **YouTube tutorials** on the side (no MIDI needed there). Connect the piano via USB to the PC for the practice tool.

If the piano only has Bluetooth MIDI and no USB-B port — buy a cheap USB-MIDI cable (~€10, one-time).

---

## The free software stack

Install once, use forever:

1. **PianoBooster** (free, open source) — https://pianobooster.sourceforge.io/
   - Falling-notes view like Synthesia. Loads any MIDI file. Listens to your MIDI input and waits for you to hit the right key. Slow-down, loop-section, hand-isolation all built in. This is your main practice tool.
2. **MuseScore 4** (free) — https://musescore.org/
   - Opens any MIDI or MusicXML file, shows sheet music, plays along, lets you slow tempo without changing pitch. Use this when you want to read notation.
3. **Chrome browser** — for web tools that use Web MIDI (pianu.com free tier, musescore.com playback, noteflight).
4. **Audacity** (free, optional) — to slow down YouTube tutorial audio without pitch change if you're learning by ear.

Free MIDI/sheet sources:
- **musescore.com** (free account, 5 downloads/month — enough)
- **IMSLP.org** — public domain classical (Debussy, free)
- **bitmidi.com**, **freemidi.org** — pop/film MIDI
- **YouTube → "Patrik Pietschmann" / "Marioverehrer" / "Peter Buka"** — Synthesia-style piano tutorials, often with downloadable MIDI in description

## The 90-day plan

### Weeks 1–2: Foundation (don't skip)
**Goal:** Hands know where notes live, both hands can move independently for 30 seconds.

- 15 min/day. Consistency beats length.
- Learn the names of the white keys (C-D-E-F-G-A-B repeating). Use the two-black-keys cluster to find C.
- Daily: play C major scale, both hands, slowly. Use fingerings 1-2-3-1-2-3-4-5 (right hand) / 5-4-3-2-1-3-2-1 (left).
- Learn 3 chords: C, G, Am, F (the "4 chords of pop"). Bonus: you can play half of pop music with these.
- Free YouTube course: **Pianote — "Piano in 21 Days"** (free intro series on YouTube, not the paid version).
- **Don't start the song list yet** unless you're dying to. The temptation is huge. Resist for 10 days.

### Weeks 3–4: Song 1 — Runaway
- Download a MIDI of the intro from musescore.com or YouTube tutorial description.
- Load in PianoBooster, set to 50% speed, hands separate.
- Goal end of week 4: play the intro at full speed, looping, smooth.
- You'll feel like a wizard. This is the dopamine hit that powers the next 60 days.

### Weeks 5–8: Song 2 — River Flows in You
- This is where you learn real hand independence.
- Left hand arpeggio pattern is repetitive — drill it 5 min/day until it's muscle memory, then add right hand.
- Tutorial: search "River Flows in You synthesia tutorial slow" — pick the one that matches the arrangement difficulty you can handle.
- Expect to plateau in week 6. Push through.

### Weeks 9–12: Songs 3 & 4 — Una Mattina + Nuvole Bianche
- Both Einaudi pieces share a structural DNA. Learning one unlocks the other.
- Start with Una Mattina (slower, less notes).
- Use MuseScore for sheet reading practice — it's time.

### Month 4+: The hard three
- Pirates → Experience → Clair de Lune. Don't rush this phase. Clair de Lune in particular is a 3–6 month commitment on its own at this level.

## Daily practice structure (15–30 min)

1. **5 min warmup** — scales + the three chords. Boring, non-negotiable.
2. **15 min focused work** — one song, one hard section, slow tempo, loop in PianoBooster.
3. **5 min "play for fun"** — whatever song you've already learned. This is your reward and it cements the work.

Rule: if you only have 10 minutes today, do steps 1 and 3. Skip the focused work rather than skipping warmup.
